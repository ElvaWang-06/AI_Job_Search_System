## Job Tracker Rules

This workspace contains `job_tracker.xlsx`, which is the single source of truth for application tracking.

### Update Rules

- Never create, delete, or modify tracker entries unless I explicitly instruct you to do so.
- Never add a job unless I explicitly tell you to add it.
- Never mark a job as **Applied** unless I explicitly confirm that I have submitted the application.
- When instructed, update only the tracker. Do not perform any other actions.

### Allowed Status Values

Use only the following status values:

- Applied
- Interview
- Final Round
- Offer
- Rejected

Do not create or use any other status.

### Never Infer or Invent

Never infer, assume, or fabricate:

- Application dates
- Resume versions
- Work authorization or sponsorship status
- Interview outcomes
- Follow-up actions
- Any missing information

If required information is missing, ask me instead of guessing.
